# Danil Shubin

[Открыть портфолио](https://melloncolie0.github.io/danil-shubin-portfolio/)

Карточки товаров, интерактивные иконки и 3D-голова. Статический сайт на GitHub Pages.

## Публикация

Полная версия сайта хранится в четырёх частях `portfolio-upload.zip.001` – `portfolio-upload.zip.004`. Workflow `.github/workflows/deploy-pages.yml` собирает архив, проверяет его контрольную сумму и публикует папку `public`.

Для обновления нужно заменить все четыре части архива и `portfolio-upload.sha256` одним коммитом. Корневые HTML, CSS и JS файлы сохранены для просмотра; опубликованная версия берётся из архива.

Для головы используется облегчённая копия той же модели с 133 772 треугольниками. Исходная модель сохранена в локальном проекте.
