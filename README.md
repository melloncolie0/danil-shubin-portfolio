# Danil Shubin

[Открыть портфолио](https://melloncolie0.github.io/danil-shubin-portfolio/)

Пять сайтов, карточки товаров, интерактивные иконки и 3D-голова. Статический сайт на GitHub Pages.

## Публикация

Полная версия хранится в нумерованных частях `portfolio-upload.zip.001`, `portfolio-upload.zip.002` и далее. Workflow `.github/workflows/deploy-pages.yml` собирает архив, проверяет его контрольную сумму и публикует папку `public`.

Для обновления нужно заменить все части архива и `portfolio-upload.sha256` одним коммитом. Корневые HTML, CSS и JS сохранены для просмотра. Опубликованная версия берётся из архива.

Сайты открываются в отдельных вкладках. Версия Константина Цыганкова включает обновлённые фотографии, видео и локальный шрифт Vetrino. Превью загружаются отдельно от самих сайтов. Видео загружаются только после нажатия.

Для головы используется облегчённая копия предоставленной модели с 133 772 треугольниками. Исходная модель сохранена в локальном проекте.
