# Danil Shubin

[Портфолио](https://melloncolie0.github.io/danil-shubin-portfolio/) · [Песочница](https://melloncolie0.github.io/danil-shubin-portfolio/sandbox.html)

В портфолио пять сайтов и карточки товаров. Песочница вынесена на отдельную страницу. В ней частицы, связи UX/UI, металлическая ткань, стеклянная линза и портал в Backrooms с ходьбой.

Backrooms открывается нажатием на портал или растягиванием его края. WASD отвечает за ходьбу, перетаскивание мышью за обзор. На телефоне после открытия появляется джойстик. Кнопка «Свернуть» или Escape возвращает исходный вид.

## Производительность

Шрифты Benzin переведены в WOFF2 без изменения контуров и метрик. Three.js загружается в сжатой версии с сохранением экспортов и имён классов. Совокупный объём этих ресурсов уменьшен с 2 441 193 до 900 790 байт. На главной код эффектов песочницы не загружается. Эффекты приостанавливаются за пределами экрана. Исходные изображения и предоставленные модели сохранены.

## Публикация

Workflow `.github/workflows/deploy-pages.yml` собирает исходный архив из `portfolio-upload.zip.001` и следующих частей, проверяет SHA-256 и распаковывает его в `public`. Затем проверяет и накладывает накопительное обновление `portfolio-update.zip`. Только папка `public` публикуется на GitHub Pages.

Для нового обновления нужно одновременно заменить `portfolio-update.zip` и `portfolio-update.sha256`. Обновление должно содержать все изменения относительно исходного архива. Корневые HTML, CSS и JS сохранены для просмотра. Полная версия сайта находится в архиве и обновлении.
